# 📖 Руководство администратора SkyBAR

## Управление контентом через админку

### 🎯 Доступ к админ-панели

1. Перейдите по адресу: `http://127.0.0.1:8000/admin`
2. Войдите используя учетные данные суперпользователя

### 📝 Управление контентом сайта

#### SiteContent (Контент сайта)

Модель **SiteContent** позволяет управлять текстовым содержимым страниц через админку.

**Типы контента:**
- **hero** - Главный баннер на главной странице
- **services** - Информация об услугах (секция "О SkyBAR")
- **contact** - Контактная информация и режим работы
- **about** - Контент страницы "О ресторане"

**Поля:**
- **Тип контента** - выберите раздел, который хотите редактировать
- **Заголовок** - основной заголовок секции
- **Подзаголовок** - дополнительный текст под заголовком (опционально)
- **Описание** - основное содержимое (поддерживает многострочный текст)
- **Изображение** - загрузить картинку для секции (опционально)
- **Активно** - включить/выключить отображение контента

**Как изменить текст на главной странице:**

1. В админке перейдите в раздел **"Контент сайта"**
2. Найдите запись с типом "Главный баннер" (hero)
3. Нажмите на неё для редактирования
4. Измените нужные поля
5. Нажмите "Сохранить"

### 👥 Управление командой

#### TeamMember (Члены команды)

Управление информацией о сотрудниках ресторана.

**Поля:**
- **Имя** - ФИО сотрудника
- **Должность** - позиция в ресторане
- **Биография** - краткое описание опыта и навыков
- **Фото** - загрузить фотографию (опционально)
- **Порядок отображения** - числовое значение для сортировки (меньше = выше в списке)
- **Активен** - показывать/скрывать на сайте

**Как добавить нового члена команды:**

1. Перейдите в **"Команда"**
2. Нажмите **"Добавить член команды"**
3. Заполните все поля
4. Укажите порядок (например, 4 если это 4-й человек)
5. Загрузите фото (рекомендуемый размер: 400x400px)
6. Нажмите "Сохранить"

### 💬 Управление сообщениями

#### ContactMessage (Сообщения обратной связи)

Просмотр и управление сообщениями от пользователей.

**Поля:**
- **Имя** - имя отправителя
- **Email** - контактный email
- **Телефон** - номер телефона (опционально)
- **Тема** - тема сообщения
- **Сообщение** - текст обращения
- **Прочитано** - отметка о прочтении

**Действия:**
- **Отметить как прочитанное** - выберите сообщения и примените действие
- **Отметить как непрочитанное** - снять отметку о прочтении

**Фильтры:**
- По статусу прочтения
- По дате создания

### 📊 Другие модели

#### Reservation (Бронирования)
- Просмотр всех бронирований
- Изменение статуса (временное/подтвержденное/отмененное/завершенное)
- Просмотр выбранных мест и деталей

#### Event (Мероприятия)
- Заявки на организацию мероприятий
- Подтверждение или отмена заявок
- Просмотр выбранных услуг

#### User (Пользователи)
- Управление учетными записями
- Изменение ролей (user/admin/staff)
- Активация/деактивация аккаунтов

#### Table & Seat (Столы и места)
- Управление столами и местами
- Изменение зон (обычная/VIP)
- Управление доступностью

#### Song & KaraokeQueue (Караоке)
- База песен
- Управление очередью исполнения
- Изменение статусов (ожидает/поет/исполнено)

## 🚀 Полезные команды

### Заполнение начального контента
```bash
python manage.py populate_initial_content
```
Создает базовый контент для главной страницы, страницы "О нас" и примеры членов команды.

### Создание суперпользователя
```bash
python manage.py createsuperuser
```

### Создание таблиц и песен
```bash
python manage.py create_tables
python manage.py populate_songs
```

### Сборка статики
```bash
python manage.py collectstatic
```

## 📸 Рекомендации по изображениям

### Фото членов команды
- **Формат:** JPG или PNG
- **Размер:** 400x400px (квадрат)
- **Вес:** не более 500KB
- **Качество:** высокое, с хорошим освещением

### Изображения контента
- **Формат:** JPG или PNG
- **Размер:** от 1200x600px
- **Вес:** не более 1MB
- **Стиль:** соответствующий общему дизайну сайта

## 🔐 Безопасность

1. **Не публикуйте** учетные данные администратора
2. **Регулярно меняйте** пароль администратора
3. **Проверяйте** сообщения обратной связи на спам
4. **Делайте бэкапы** базы данных перед большими изменениями

## ❓ FAQ

**Q: Как изменить режим работы ресторана?**
A: Перейдите в "Контент сайта" → найдите тип "Контакты" → измените описание.

**Q: Не отображается изменение на сайте?**
A: 
1. Проверьте, что контент помечен как "Активно"
2. Очистите кэш браузера (Ctrl+Shift+R)
3. Проверьте, что поле заполнено корректно

**Q: Как скрыть члена команды?**
A: В разделе "Команда" → выберите сотрудника → снимите галочку "Активен" → Сохранить.

**Q: Можно ли добавить несколько записей одного типа контента?**
A: Нет, каждый тип контента уникален. Если нужно добавить новый тип - обратитесь к разработчику.
