# Руководство по контрибьюции

Спасибо за интерес к проекту SkyBAR! 🎉

## Как начать

1. Fork репозитория
2. Клонируйте ваш fork
3. Создайте ветку для вашей фичи
4. Делайте изменения
5. Напишите тесты
6. Создайте Pull Request

## Стиль кода

### Python
- Следуйте PEP 8
- Используйте Black для форматирования
- Максимальная длина строки: 120 символов
- Используйте type hints где возможно

```bash
# Форматирование кода
black restaurant skybar

# Проверка стиля
flake8 restaurant --max-line-length=120

# Сортировка импортов
isort restaurant skybar
```

### JavaScript
- Используйте ES6+
- Именование переменных: camelCase
- Константы: UPPER_CASE
- Комментируйте сложную логику

### CSS
- Используйте осмысленные имена классов
- Группируйте связанные стили
- Добавляйте комментарии для секций

## Тестирование

Все новые фичи должны сопровождаться тестами:

```bash
# Запуск тестов
pytest

# С покрытием
pytest --cov=restaurant

# Конкретный тест
pytest restaurant/tests/test_models.py
```

## Коммиты

Используйте понятные сообщения коммитов:

```
feat: Добавлена возможность редактирования бронирований
fix: Исправлена ошибка в выборе времени
docs: Обновлена документация
test: Добавлены тесты для караоке
refactor: Рефакторинг views.py
style: Улучшены стили формы бронирования
```

## Pull Request

1. Обновите свою ветку с main
2. Убедитесь что все тесты проходят
3. Опишите изменения в PR
4. Прикрепите скриншоты если это UI изменения
